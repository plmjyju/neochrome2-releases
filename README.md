# NeoChrome2 安装包

这里只放 NeoChrome2（仓库打单浏览器）的安装包和自动更新文件，不放代码。

- 新电脑安装：下载 [NeoChrome2-win-Setup.exe](https://github.com/plmjyju/neochrome2-releases/releases/latest/download/NeoChrome2-win-Setup.exe)，这是当前正式版。第一次运行时如果 Windows 提示“已保护你的电脑”，点“更多信息 → 仍要运行”。
- 已经装了 NeoChrome2 的电脑会自动更新，不用来这里下载。
- 标着 Pre-release 的版本在测试渠道上，只给做现场测试的电脑。

每个版本改了什么、现场要测哪些网站，见 [Releases](https://github.com/plmjyju/neochrome2-releases/releases)。
